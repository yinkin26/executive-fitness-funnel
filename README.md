# Executive Metabolic Protocol™ - AI Funnel Demo

这是一个专为 **欧美高客单在线健康与体能教练（Online High-Ticket Fitness/Health Coach）** 定制的高转化销售漏斗（Booking Funnel）实战演示项目。

---

## 🌟 页面核心亮点与转化设计

1. **精准受众（Target Audience）**：年薪 6-7 位数的企业高管、创始人（60+ 小时工作制，没时间长泡健身房）。
2. **高转化文案框架（Direct Response Copywriting）**：
   - **Hero Hook**：直击痛点，反常规认知（不需要挨饿、不需要疯狂做有氧）。
   - **The Problem**：传统健身方案为什么必定让创业者失败。
   - **The 3-Pillar Method**：代谢重启 + 35分钟最低有效剂量训练 + 睡眠与皮质醇监控。
   - **Social Proof**：CEO 真实案例前后数据（Marcus 减重 26 磅，Sarah 减脂 8%）。
   - **Ironclad Guarantee**：90 天达不到目标继续免费辅导，零风险承诺。
3. **交互系统（Lead Qualification & Calendar Modal）**：
   - 点击任何 CTA 按钮会触发 **3-Step 资格筛选问卷**，模拟从线索筛选到日历预约的全自动化链路。

## 🚀 如何一键部署上线（Vercel 免费托管）

按照课程模块 `2. AI 網站製作 (AI Funnel)\11. 如何用 Github 和 Vercel 把設計好的網站 Live 出來.mp4`：

1. **上传至 GitHub**：
   - 在 GitHub 新建一个仓库（例如 `executive-funnel-demo`）。
   - 将该文件夹内的 `index.html` 上传到仓库。
2. **连接 Vercel**：
   - 登录 [vercel.com](https://vercel.com)。
   - 点击 **"Add New" ➔ "Project"**，选择该 GitHub 仓库。
   - 点击 **"Deploy"**，30 秒后即可获得一个全球访问的链接（如 `https://apex-metabolic.vercel.app`）。
3. **出海谈单武器**：
   - 将这个链接发给外国潜在客户预览，直接作为你个人 AI Agency 的 Live Portfolio 案例！
